Dong Hui Thong Bao Web v1.9

Cap nhat chinh:
- Mo app la hien biên ban, cac cai dat an trong nut banh rang.
- Nut xuat file an trong nut tai xuong tren thanh tren.
- Tu dong Fit to Screen tren dien thoai/tablet, khong con mac dinh 100% lam cat ngang.
- Ho tro pinch zoom hai ngon tay tren khu vuc bien ban.
- Cham chu mau xanh de mo popup sua nhanh.
- Popup toi uu cho ban phim ao Android/iPhone bang VisualViewport va chieu cao dong.
- Sua loi code JavaScript bi hien thanh chu ben duoi trang.
- Bo banner quang cao o dau trang.
- Giu tinh nang PNG/PDF/Word va Google Drive sync.

Trien khai:
1. Upload toan bo noi dung thu muc nay len GitHub.
2. Ket noi repository voi Vercel, Framework Preset = Other.
3. Deploy.
4. Neu dung Google Drive: cau hinh Google OAuth Web Client ID va them domain Vercel vao Authorized JavaScript origins.
