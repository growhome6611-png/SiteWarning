Dong Hui Notification Web v2.0

Thay doi chinh:
1. Zoom + pan:
   - 2 ngon tay pinch zoom.
   - Sau khi zoom, keo 1 ngon tay de pan trai/phai/len/xuong.
   - Nut Vua man hinh giu nguyen.

2. Google OAuth:
   - Kiem tra Web Client ID truoc khi dang nhap.
   - Client ID hop le phai co dang: 123456789-abc.apps.googleusercontent.com
   - Khong nhap URL, API key hoac Client Secret.
   - Tren Google Cloud can tao OAuth 2.0 Client ID loai Web application va them domain Vercel vao Authorized JavaScript origins.
   - Can bat Google Drive API cho project.

3. Cai dat gon:
   - An cac truong Ten cong trinh, Ten hang muc, Don vi thi cong, Ma hop dong.
   - An cac truong ten nguoi ky va Ngay lap bien ban.
   - Cac truong nay sua truc tiep bang cach cham vao chu mau xanh tren bien ban.

4. Chen anh:
   - Them nut + Chen anh ngay tai dong Anh chup + tai lieu dinh kem.
   - Nut khong xuat hien trong anh/PDF/Word.

5. Cache:
   - Cap nhat service worker cache v2.0 de tranh giu ban cu.
